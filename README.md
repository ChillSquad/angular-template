## Angular SSE - статус пользователя в реальном времени

Сервер раз в 3 секунд пушит в браузер сообщение о том, в сети пользователь или нет.\
Показывает поток сообщений и позволяет «войти» / «выйти» с сервера.

## Запуск

Нужны два параллельно работающих процесса.

**Терминал 1 - SSE-сервер:**

```bash
node server/server.js
```

**Терминал 2 - Angular:**

```bash
ng serve
```
